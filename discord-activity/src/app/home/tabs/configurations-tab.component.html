Outside Party Signup

Let Discord-server members who have never launched the app sign up for events from the party board, identified by their Discord account. Their first signup adds them to your roster as a placeholder member, so they earn DKP and count toward attendance like anyone else (and aren't re-asked for their name next time).

Fill alliances in order

When someone signs up for a later alliance while an open slot their job can fill is still free in an earlier alliance, they're warned and offered that earlier slot first. A soft, job-aware nudge (they can still sign up where they chose); no effect on single-alliance events.

HNM Outside Sign Up

A separate switch for HNM signup boards. Turning this on adds the HNM event type when creating an event and lets outside Discord members sign up to HNM boards. HNM is roster memory only — players are remembered so they don't retype their name, but HNM signups earn no DKP and no attendance credit. Works independently of Outside Party Signup above.

Components V2 boards (experimental)

Post Discord event sign-up boards as Discord Components V2 messages: the rendered board sits in a full-width media gallery (no embed frame) and is drawn on a wider canvas, so it reads larger. Same buttons and signup flow. Discord won't let a board switch modes once posted, so this only affects boards posted after you turn it on.

LSM
LinkshellManager Addon

LSM Game Addon

The LSM addon is a small in-game addon for Ashita v3 (FFXI). Once paired to your linkshell, it sends data into LinkshellManager app in real time.

ASHITA V3 FFXI
✦

What it can do

📅

Timed Event Management

Create, browse, and run timed events from the in-game launcher (/attend). Queued events sync from the web and Discord, and members can sign up and be marked present without leaving the game.

📸

Attendance snapshots

Capture everyone in your party, zone, or alliance and post them as a Window Event. Add a monster name to auto-tag the camp (Kings / Wyrms / Misc).

⏱️

Time-of-Death tracking

Watches chat for kills, tracks pop windows, and sends the results to the ToDs tab.

🔄

Real-time sync

Anything captured by the addon appears in LinkshellManager while it's paired.

🛠️

Setting it up

  1. 1

    Install it

    Copy the lsm folder into Ashita/addons/lsm/ and run /addon load lsm.

  2. 2

    Set the server

    Run /lsm server https://linkshellmanager.com

  3. 3

    Pair the linkshell

    Click + Get Code below, then run /lsm link <code> in FFXI.

  4. 4

    Use it

    Open attendance with /attend, take a snapshot with /lsm now, or open ToD tracking with /tod.

⌨️

Handy commands

/lsm now [name] [p|z|a]

Snapshot your party, zone, or alliance.

/attend

Open or close the attendance window.

/tod

Open or close the Time-of-Death tracker.

/lsm status

Show the server URL and pairing status.

/lsm help

Print the full in-game command list.
