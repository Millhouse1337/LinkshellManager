HNM Outside Sign Up

A separate switch for HNM signup boards. Turning this on adds the HNM event type when creating an event and lets outside Discord members sign up to HNM boards. HNM is roster memory only — players are remembered so they don't retype their name, but HNM signups earn no DKP and no attendance credit. Works independently of Outside Party Signup in Customize Linkshell.

HNM Attendance Mode (Manual Check In)

Manual Check In: members self-serve Check In from a button on the Discord camp board, marking the window they arrived. DKP is per window attended (a fraction like 0.25) plus optional claim / kill bonuses. Standard scores from the addon's window scans: open to everyone scanned in window 1, close to everyone in the camp's last scan, plus claim / kill for the outcome entered on the End Camp form. Leave a bonus at 0 to switch it off. (HNM Outside Sign Up should be on so account-less members can Check In.)

Either way these amounts are only what a camp proposes. Ending a camp no longer pays anyone: it posts the roster to Current Field Activity on the Event System tab as a pending row, and DKP moves when an officer reviews it and hits Post — so a camp with every bonus at 0 still shows up there and can be priced by hand. Changing this applies to new boards and to any camp that hasn't started yet — a camp already running keeps its current mode until it pops, because switching mid-camp would strand the attendance already collected.

Automatic window snapshots

When on, an officer running the LSM addon can arm auto-posting on a live camp. About the delay below after each window opens, the addon captures their alliance (not the whole zone) and posts it as that window's attendance snapshot. Arming is per-officer and per-camp — never automatic — so people in the zone who shouldn't be counted stay out. If the camp runs more than one alliance, one officer in each alliance must arm. Only members who can moderate live events can arm.
Standard: these snapshots are what the open / close / claim / kill bonuses are paid from. Manual Check In: they are a record only — DKP still comes from Check In / Check Out.

LSM
LinkshellManager Addon

LSM Game Addon

The LSM addon is a small in-game addon for Ashita v3 (FFXI). Once paired to your linkshell, it sends data into LinkshellManager app in real time.

ASHITA V3 FFXI
✦

What it can do

📅

Timed Event Management

Create, browse, and run timed events from the in-game launcher (/attend). Queued events sync from the web and Discord, and members can sign up and be marked present without leaving the game.

📸

Attendance snapshots

Capture everyone in your party, zone, or alliance and post them as a Window Event. Add a monster name to auto-tag the camp (Kings / Wyrms / Misc).

⏱️

Time-of-Death tracking

Watches chat for kills, tracks pop windows, and sends the results to the ToDs tab.

🔄

Real-time sync

Anything captured by the addon appears in LinkshellManager while it's paired.

🛠️

Setting it up

  1. 1

    Install it

    Copy the lsm folder into Ashita/addons/lsm/ and run /addon load lsm.

  2. 2

    Set the server

    Run /lsm server https://linkshellmanager.com

  3. 3

    Pair the addon (once)

    Click + Get Code below, then run /lsm link <code> in FFXI. One code pairs every linkshell you belong to — no need to repeat it per linkshell.

    The addon then lists whichever of them are on your two equipped pearls. If a linkshell's members aren't showing, equip its pearl.

  4. 4

    Use it

    Open attendance with /attend, take a snapshot with /lsm now, or open ToD tracking with /tod.

⌨️

Handy commands

/lsm now [name] [p|z|a]

Snapshot your party, zone, or alliance.

/attend

Open or close the attendance window.

/tod

Open or close the Time-of-Death tracker.

/lsm status

Show the server URL and pairing status.

/lsm help

Print the full in-game command list.

Game Addon (lsm)

Generate a one-time pairing code, then in FFXI type /lsm link <code> to connect the addon. One code covers every linkshell you belong to — you only need to do this once, not per linkshell.

In game, the addon only lists the linkshells on your two equipped pearls. If a linkshell's members aren't showing up, check that its pearl is equipped.

Revoking disconnects the addon from every linkshell that code paired, not just this one.
